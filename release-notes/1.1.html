Watched folders

  • Settings › Watched Folders: pick folders and every new video or audio file that lands in them is transcribed automatically, with the outputs you choose (SRT, WebVTT, text, Markdown, or a project file) saved next to it. A notification tells you when each file is done.
  • Files already in a folder are left alone; new ones are picked up once they have finished copying.
  • Open at Login: Transcriber can start quietly in the background so watched folders are always handled.
