SOAP note export

  • File › Export › SOAP Note writes a medical-style SOAP note from the transcript: a bullet-point summary, Subjective, Objective, Assessment and Plan sections with the usual fields, and a plain-language discharge summary for the patient. It is written by Apple's on-device model, so the recording and the note never leave your Mac. Requires Apple Intelligence.
  • SOAP notes can also be produced automatically for watched folders.
